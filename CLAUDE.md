# Begin nu – werkafspraken

- Doel van de app: helpen *beginnen* met studeren. Lees BOUWINSTRUCTIE.md §1 voordat je features toevoegt.
- Niets blokkeren, niets straffen, geen schuldgevoel in teksten of cijfers.
- Alle interfaceteksten staan in src/copy.ts, in het Nederlands, tutoyerend, zonder uitroeptekens.
- Logica (timer, streak, stats, storage) blijft puur en DOM-vrij, met tests.
- Timers zijn altijd gebaseerd op een absoluut endAt-tijdstip.
- Geen nieuwe runtime-dependencies zonder te vragen.
- Voor een commit: npm run lint && npm run typecheck && npm test.
- Commitberichten in het Nederlands, kort en in de gebiedende wijs ("Voeg parkeerplaats toe").
